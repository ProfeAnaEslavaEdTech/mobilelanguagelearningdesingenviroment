# Design Principles

The architecture follows three independent layers:

## Layer 1 — Game Engine

Defines **how the GPT behaves**.

Includes:

- Identity
- Personality
- Conversation flow
- Decision logic
- Safety
- Evaluation
- Memory

---

## Layer 2 — Game Design

Defines **how the game works**.

Includes:

- Story
- Levels
- Quests
- NPCs
- Bosses
- Progression
- Rewards
- Mechanics

---

## Layer 3 — Knowledge Base

Defines **what the GPT knows**.

Includes:

- Curriculum
- Documents
- Research
- References
- Internal resources
- Rubrics
- Examples

---

This separation ensures that behavioral logic, game mechanics, and educational content remain modular, reusable, and easy to maintain as the project evolves.
