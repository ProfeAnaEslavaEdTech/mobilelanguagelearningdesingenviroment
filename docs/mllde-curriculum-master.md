## 1. Purpose and scope

This is the master design document for the **Mobile Language Learning Design Environment (MLLDE)** — the umbrella methodology of the project — and the reference against which every **Language Passport** lesson and level is planned and built. It defines the method, the international standard it is anchored to (CEFR), the language data base it draws on (the *Plan curricular del Instituto Cervantes*), the reusable lesson blueprint, the planning template, and the Language Passport curriculum produced so far.

**Golden rule of the document:** MLLDE is language-agnostic. The **level** and the **can-do content** come from CEFR (universal); only the **filling** — vocabulary, grammar, functions, culture — changes per language.

---

## 2. MLLDE — the method

MLLDE is a **replicable design procedure** that converts one CEFR can-do target into a short, gamified, mobile lesson — through a fixed pedagogical cycle, filled with per-language data, and checked against the CEFR competences and modes. It is the **how**, distinct from the standard, the content, and the product.

### 2.1 The four-layer model

| Layer | Name | Question it answers |
|---|---|---|
| **Standard** | CEFR (Council of Europe) | *What* to learn, and *how far* (A1→C2 can-do targets) |
| **Method** | **MLLDE** — this document | *How* to turn any target into a lesson |
| **Data** | Per-language content | *Which* words, chunks, grammar, functions, culture |
| **Product** | Language Passport | The *first thing built* with the method |

*CEFR gives the destination; the language data is the cargo; MLLDE is the repeatable vehicle that gets any learner there, in any language.*

### 2.2 What MLLDE is NOT

- **Not the app (Language Passport).** The app is the first product; the method could produce many others.
- **Not CEFR.** CEFR is the standard it plugs into; MLLDE adds no levels — it delivers them.
- **Not the language content.** Words, grammar and culture are swappable data; MLLDE is language-agnostic.
- **Not a single approach or theory.** It orchestrates several frameworks; the originality is the synthesis.
- **Not a grammar checker or an AI.** The rules, the grammar book and Grace are components inside the method.
- **Not a fixed set of lessons.** Barcelona and Sevilla are instances; the method generates lessons.
- **Not a syllabus or textbook.** It is a generative procedure, not static content.
- **Not a technology or platform.** The PWA is today's delivery; the engine-plus-data idea is portable.
- **Not a certification body.** It aligns to CEFR but issues no diplomas; it gates mastery within a lesson.

**Boundary in one line:** *MLLDE is not the standard, not the content, not the product, not any one theory, and not the technology — it is the method that binds a CEFR target, a language's data, and a synthesis of frameworks into a replicable, playable mobile lesson.*

## 3. The CEFR competence core

The **CEFR** (Common European Framework of Reference for Languages), developed by the **Council of Europe**, replaces the traditional four skills with **four dynamic modes of communication**, powered by a core block of **three communicative language competences**. Every MLLDE lesson or level is specified against this core.

### 3.1 The four modes of communication

- **Reception** — receiving and processing spoken/written language without producing a new message (reading, listening).
- **Production** — constructing and delivering a continuous text to silent listeners/readers (a talk, an essay).
- **Interaction** — a joint exchange where parties alternate reception and production (conversation, debate, chat).
- **Mediation** — acting as a social agent to bridge people, texts or cultures (translate, summarise, explain across cultures).

### 3.2 The three communicative language competences

```
┌────────────────────────────────────────────────────────┐
│           COMMUNICATIVE LANGUAGE COMPETENCES           │
└───────┬───────────────────┬────────────────────┬──────┘
        │                   │                    │
┌───────▼───────┐   ┌───────▼───────┐    ┌───────▼───────┐
│  Linguistic   │   │Sociolinguistic│    │   Pragmatic   │
│  (Grammar /   │   │  (Cultural /  │    │  (Function /  │
│  Vocabulary)  │   │  Politeness)  │    │  Coherence)   │
└───────────────┘   └───────────────┘    └───────────────┘
```

| Competence | Covers | In MLLDE it lives in… |
|---|---|---|
| **Linguistic** | grammar, vocabulary, syntax, spelling | vocab, chunks, gap-fill, grammar (rules + book + Grace) |
| **Sociolinguistic** | register, politeness, cultural reference | culture & pragmatics cards; *nos pone…* vs *quiero* |
| **Pragmatic** | function, coherence, discourse | the mission (polite order); dialogue; reflection |

### 3.3 Summary matrix — modes × competences

| Mode | Linguistic | Sociolinguistic | Pragmatic |
|---|---|---|---|
| **Reception** | complex sentence syntax | regional accents / registers | overall tone & intent |
| **Production** | accurate vocabulary | adapt to a formal audience | structure with transitions |
| **Interaction** | correct verb tenses | conversational fillers | manage turn-taking |
| **Mediation** | translate precise terms | explain taboos across cultures | simplify a text into a summary |

### 3.4 Level rule for the modes

**Reception · Production · Interaction** apply at every level from A1 upward. **Mediation** is introduced from **B2 onward (B2 · C1 · C2)**, where the learner can relay, explain and simplify a text or concept for someone else. *(CEFR defines simpler mediation at lower levels; MLLDE positions the mediation* mode *as an upper-level competence.)*

**The four-word summary:** competence = *what*; mode = *how it is used*; level = *how far*; MLLDE = *the method*.

## 4. The international standard and the language data base

Two source families anchor the curriculum: the **universal standard** (CEFR — Council of Europe) and, for each language, that language's **official CEFR-aligned content reference** — for Spanish, the *Plan curricular del Instituto Cervantes*.

### 4.1 The standard — CEFR (Council of Europe)

The **CEFR** (Common European Framework of Reference for Languages) is the standard of the **Council of Europe**. It grew out of decades of work — it *"did not suddenly appear from nowhere in 2001, but was a development over a period of time"* — that offered a fresh way of communicating teaching aims, more conducive to the **operational appropriation of an unfamiliar language**: by identifying real language needs, it pinpointed the knowledge and know-how required to reach a communicative **"threshold."** The CEFR organises proficiency into **six levels, A1–C2**, regrouped into three broad bands — **Basic User (A1–A2)**, **Independent User (B1–B2)** and **Proficient User (C1–C2)** — which local contexts may further subdivide. Every level is defined through **"can-do" descriptors.**

> **Council of Europe — CEFR level descriptions:** <https://www.coe.int/en/web/common-european-framework-reference-languages/level-descriptions>

### 4.2 The Spanish content standard — Plan curricular del Instituto Cervantes

MLLDE anchors the **method** to CEFR (universal), which is what makes it language-agnostic. The **content** for a given language is drawn from that language's official, CEFR-aligned reference. **For Spanish, Language Passport uses the *Plan curricular del Instituto Cervantes*** — the curriculum of the **Instituto Cervantes**, the official institution for the teaching of Spanish — to **unify its programmatic content** (Gramática, Funciones, Nociones…). *(For another language, its own official CEFR-aligned reference would be used.)*

> **Plan curricular del Instituto Cervantes:** <https://cvc.cervantes.es/ensenanza/biblioteca_ele/plan_curricular/default.htm>

### 4.3 Sources held (`docs/sources/`)

| Source | Feeds | Levels |
|---|---|---|
| CEFR Descriptors 2020 (EN/FR/DE/IT/ES) | the standard — levels + 4 modes (~1,832 can-do) | Pre-A1 → C2 |
| CVC *Plan curricular* — Gramática (Glosario + Inventarios) | **Linguistic** competence (forms) | A1-A2 · B1-B2 · C1-C2 |
| CVC *Plan curricular* — Funciones (Inventarios) | **Pragmatic** competence (functions) → Interaction | A1-A2 · B1-B2 · C1-C2 |

**Still to add for full Spanish coverage:** Nociones (vocabulary → Linguistic); Saberes y comportamientos socioculturales + Referentes culturales (→ Sociolinguistic); Tácticas y estrategias pragmáticas + Géneros discursivos (→ Pragmatic/discourse); Pronunciación y Ortografía (→ Linguistic).

## 5. The MLLDE design procedure

### 5.1 Input contract
Every lesson begins from a **CEFR level + a can-do descriptor + a real-world scenario**. Example: A2 · "Can order a meal" (scale: *Obtaining goods and services*) · scenario: a Barcelona tapas bar.

### 5.2 Build process — SAM
Lessons are produced through the **Successive Approximation Model (SAM)**: a preparation phase, an iterative design "savvy start", then iterative build cycles — prototype, review, refine. This is why MLLDE is a *method* (a repeatable process), not a one-off artefact.

### 5.3 Frameworks synthesised (credited)

| Framework | Contribution to MLLDE |
|---|---|
| SAM (Allen & Sites, 2012) | the iterative build process |
| G-CLIL / IPO (Casañ-Pitarch, 2017) | the gamified Input–Processing–Output cycle |
| CLIL 4Cs (Coyle, 2007/2010) | Content · Communication · Cognition · Culture |
| ESA (Harmer, 2007) | Engage–Study–Activate staging |
| CTL / REACT (Johnson, 2002; CORD/Crawford, 2001) | contextual, authentic tasks |
| Lexical Approach (Lewis, 1993) | teaching in chunks |
| Dual-coding / multimedia (Mayer, 2009) | animated, image-supported vocabulary |
| Interlanguage pragmatics (Kasper & Rose, 2001) | the register / politeness cards |
| Mobile Learning Design (Clothier, 2026) | short, one-handed mobile delivery |
| CEFR (Council of Europe, 2020) | the leveling & competence standard |

### 5.4 How the frameworks map to the lesson cycle

§5.3 lists the frameworks (the *theory*); §6.2 shows *where each one fires* as the learner moves through a lesson. This crosswalk links the two. Four elements are **cross-cutting** — they shape every step rather than sitting in one row: **SAM** (the build process), **Mobile Learning Design** (the delivery), **CEFR** (the level & mode/competence targets) and the **Plan curricular · Instituto Cervantes** (the Spanish content).

| Lesson step (mode) | Framework(s) it operationalises |
|---|---|
| Whole arc (IPO) | G-CLIL / IPO (Casañ-Pitarch); ESA (Harmer); CLIL 4Cs (Coyle) across all |
| Arrival — hook/objective | ESA "Engage"; CTL meaningful connection |
| Vocabulary (animated) — *Reception* | Dual-coding/multimedia (Mayer); Lexical Approach (Lewis); IPO *Input* |
| Chunks — *Reception/Production* | Lexical Approach (Lewis); functional chunks → pragmatics (Kasper & Rose) |
| Model dialogue — *Reception* | IPO *Input*; CLIL *Communication*; register → pragmatics (Kasper & Rose) |
| Gap-fill — *Processing* | IPO *Processing*; ESA "Study→Activate" bridge |
| **Mission — *Interaction*** | CTL / REACT (authentic task); ESA "Activate"; IPO *Output*; pragmatics; G-CLIL gamification |
| Reflection (Speak/Write) — *Production* | IPO *Output*; REACT "Transferring"; CTL self-regulated learning |
| Culture & pragmatics cards | CLIL 4Cs *Culture*; pragmatics (Kasper & Rose) |
| Rewards | G-CLIL gamification ring (Casañ-Pitarch); motivation |

**In one line:** §5.3 is *what MLLDE is made of*; §6.2 is *where each of those things fires* — and CEFR is the ruler every step is measured against.

## 6. The lesson blueprint

### 6.1 Engine + data (the Destination Schema)
The lesson cycle is a **shared engine**; a lesson is a **data object** (the Destination Schema). Building a new lesson — or a whole new language — is *filling in data*, not rewriting logic. That is the method's core innovation and the reason it is replicable across languages.

### 6.2 The lesson cycle (IPO) mapped to modes & competences

| Step | Mode | Competence |
|---|---|---|
| Arrival (hook, objective) | — | sets the scenario |
| Vocabulary (animated) | Reception | Linguistic |
| Chunks | Reception / Production | Linguistic + Pragmatic |
| Model dialogue | Reception | Linguistic + Sociolinguistic |
| Gap-fill | Processing | Linguistic (formative) |
| **Mission (authentic assessment)** | **Interaction** | Pragmatic + Sociolinguistic |
| **Immediate Assessment — "Don't give up!" (Speak / Write)** ★ | **Production** | all three |
| Culture & pragmatics cards | — | Sociolinguistic |
| Rewards | — | motivation |

★ **Mandatory step (see §8.1).** The output/transfer step is delivered with the
**Immediate Assessment** standard and is labelled **"Don't give up!"** (encouraging,
never "fail"). It is a required component of *every* lesson.

## 7. Lesson / level planning template (standing rule)

**Every lesson or level plan must fill this before anything is built.** It guarantees CEFR alignment and international comparability.

**Header:** language · CEFR level (Pre-A1…C2) · scenario/destination · target can-do descriptor(s).

| Mode | What this lesson does (fill) | Applies at |
|---|---|---|
| **Reception** | listening + reading targets | A1+ |
| **Production** | spoken + written monologue targets | A1+ |
| **Interaction** | spoken + written exchange targets | A1+ |
| **Mediation** | relay / explain / simplify a text or concept | **B2+** |

**Competences block (fill for each):** Linguistic (vocabulary · chunks · grammar points); Sociolinguistic (register · politeness · culture); Pragmatic (functions · discourse · coherence).

**Mandatory components (every lesson, non-negotiable):** an authentic-assessment
**Mission** (§6.2) and the **Immediate Assessment — "Don't give up!"** output step with
its non-punitive feedback + retry + **Ask-Grace** escalation (§8.1). A plan is not
complete unless both are present.

## 8. Assessment, feedback and motivation

- **Authentic assessment.** A real-world mission is the gate — mastery, not a score (CTL).
- **Feedback ladder.** Offline rules (spelling, agreement, missing auxiliary) → the grammar book (deep-linked) → **Grace**, the AI mentor, for open-ended correction.
- **Motivation.** A global wallet (coins, passport stamps, souvenirs), a rank path (Hitchhiker → Travel Ambassador) and a world-tour map.

### 8.1 Immediate Assessment — mandatory design standard

**Every city/lesson — already built or to be developed — must implement the
Immediate Assessment component** at the output/transfer step. It is inherited from
the shared engine, so existing destinations (Barcelona, Sevilla) already comply; any
new destination inherits it automatically and **must not** remove or weaken it.

**Required behaviour**

1. **Two output modes.** The learner chooses **🎙️ Speak** or **✍️ Write** to deploy the language in a new context (REACT — transfer; Crawford/CORD, 2001).
2. **Instant, specific check** of the learner's production against the lesson data:
   vocabulary (incl. wrong-language/English words), spelling (edit-distance near-miss),
   known grammar confusions, and required auxiliaries — plus a minimum-length / target-word gate.
3. **Non-punitive feedback.** Errors are shown in **warm amber with a 🤔 "not sure" icon — never red** (red discourages learners). Feedback is **specific** (says *what* and *why*, with a short example) and **bilingual** (target-language first, brief English gloss).
4. **Retry, always.** The learner is invited to fix it and try again — unlimited, encouraging attempts; success is celebrated (coins + stamp).
5. **Escalation to the AI mentor (mandatory button).** Every non-success state shows a **"🌊 Pregúntale a Grace — explica y corrige"** button that hands the learner's sentence + the flagged mistake to **Grace TOP** for an open-ended grammar/vocabulary explanation.
6. **Encouraging label.** The step is titled **"Don't give up!"** (not "Reflexión"/"fail").

**Pedagogical basis.** Formative assessment / feedback-for-learning; mastery-learning
retry; affective-filter reduction (non-punitive colour + tone); REACT *Transferring*;
CTL authentic, low-stakes assessment. This is the MLLDE realisation of *assessment as
learning*, not *of* learning.

## 9. Language Passport — curriculum so far

**Language Passport** is Project 1 of MLLDE: a gamified, offline-capable mobile app teaching Spanish for travellers. Two destinations are built (Barcelona, Sevilla), both CEFR A1–A2. Each is specified below by **mode × competence × level**, with the CVC *Plan curricular* items it realises.

### 9.1 Barcelona — "De Tapas Por La Rambla"

- **Scenario:** ordering food & drinks at a tapas bar · **CEFR level:** A1–A2 · **Language:** Spanish
- **CEFR scale / descriptors:** *Obtaining goods and services* — A1 "Can ask for food and drink using basic expressions"; A2 "Can order a meal." Reflection: *Sustained monologue — describing experience* (A1–A2).
- **Modes:** Reception (model dialogue) · Production (reflection: Speak/Write) · Interaction (the ordering mission). Mediation: not at A1–A2.

| Competence | CVC *Plan curricular* items realised |
|---|---|
| **Pragmatic (Funciones)** | 4.3 Pedir objetos · 4.2 Pedir un favor · 4.14 Ofrecer e invitar · 1.2 Pedir información / 1.3 Dar información · 3.2 Expresar gustos e intereses |
| **Linguistic (Gramática)** | 1. El sustantivo (género y número — *patatas/bravas* concordancia) · 2. El adjetivo (concordancia) · 3. El artículo (*unas/las*) · 9. El verbo (presente; pretérito perfecto *he comido*, A2) |
| **Sociolinguistic** | 5.1 Saludar / 5.2 Responder a un saludo · 5.12 Agradecer · register: *nos pone… / ¿me pone…?* vs *quiero* |

**Content:** Vocabulary — las patatas bravas, la tortilla española, una cervecilla, los pinchos, el agua, la cuenta. Chunks — *¿me pone…?, nos pone…, por favor, ¿y para beber?* Mission — order ≥2 tapas + ≥2 drinks politely. Culture — La Rambla, Miró, La Boquería, *"nos pone…, not quiero."* Reward — Barcelona stamp; souvenirs.

### 9.2 Sevilla — "De Bares por Santa Cruz"

- **Scenario:** ordering tapas & drinks in an Andalusian bar · **CEFR level:** A1–A2 · **Language:** Spanish
- **CEFR scale / descriptors:** *Obtaining goods and services* (as above); adds asking for a recommendation and expressing preference.
- **Modes:** Reception · Production · Interaction. Mediation: not at A1–A2.

| Competence | CVC *Plan curricular* items realised |
|---|---|
| **Pragmatic (Funciones)** | 4.3 Pedir objetos · 4.14 Ofrecer e invitar · 2.1 Pedir opinión / recomendación · 3.4 Preguntar por preferencias / 3.5 Expresar preferencia · 1.2 / 1.3 Pedir / Dar información |
| **Linguistic (Gramática)** | 1. El sustantivo · 2. El adjetivo · 3. El artículo · 9. El verbo (presente); *tinto de verano* — preposición *de* (sintagma nominal) |
| **Sociolinguistic** | 5.1 Saludar / 5.2 Responder · 5.12 Agradecer · register: *una caña* (local usage) vs *una cerveza* |

**Content:** Vocabulary — el salmorejo, el pescaíto frito, una caña, un tinto de verano, la tapa, la cuenta. Chunks — *¿me pone…?, para mí…, ¿qué me recomienda?, por favor.* Mission — order ≥2 tapas + ≥2 drinks politely. Culture — La Giralda, orange trees, salmorejo vs gazpacho, *"una caña."* Reward — Sevilla stamp; souvenirs.

### 9.3 Roadmap

- **Levels:** current lessons target A1–A2; the framework scales to B1–B2 and C1–C2 using the same CVC inventories. Mediation tasks enter at **B2**.
- **Destinations:** Europe · España live (Barcelona, Sevilla); Africa · Asia · America · Oceania locked ("próximamente").
- **Languages:** the method is language-agnostic — the same A2 "order a meal" target can generate a French *café* or German *Biergarten* lesson from that language's data.
